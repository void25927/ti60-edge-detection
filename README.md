# 可配置 FPGA 实时视觉质检平台

## 打开与编译

* 开发板：VF-Ti60F225；摄像头：SC2210；视频目标：1920×1080@60fps。
* 使用 Efinity 2023.2 打开本目录的 Ti60\_Edge\_Detection.xml，顶层为 Ti60\_top。
* Ti60\_Edge\_Detection.peri.xml 保存外设及引脚配置，Ti60\_Edge\_Detection.pt.sdc 保存时序约束，均须保留。
* 从综合开始执行完整编译。work\_syn、work\_pnr、work\_pt 等目录由工具重新生成。
* 不要将 sim 中的 testbench 加入 Design 源码列表。
* UI 字库已随 src/ui 保存，编译时以工程根目录为工作目录，无须重新生成字库。
* Ti60\_Edge\_Detection.f 是辅助仿真文件列表；其中 Efinity 模型路径按原安装位置 C:/Efinity/2023.2 保存，换电脑时应按实际工具位置调整。综合以 XML 为入口。
* 厂商 IP 原样保留。settings.json 中存在厂商生成时的历史绝对路径；现有工程使用本地生成源码，不应直接按历史路径重新生成 IP。

## 目录

|文件或目录|用途|
|-|-|
|Ti60\_top.v|正式顶层|
|src/|图像算法、控制、轮廓校对、同帧缓存及 UI 的 RTL 和 ROM 资产|
|ip/|厂商 DDR、FIFO IP 源码、配置和配套文件|
|pri/|厂商 MIPI 接收源码|
|sim/|自检源码及运行脚本，不含生成的工作库和历史日志|
|docs/modern\_ui.md|菜单、按键及界面说明|
|outflow/|清理前已存在的位流、接口文件及主要编译/资源/时序报告|

## 使用

功能键短按循环选择六个菜单；各菜单操作见 [操作说明](docs/modern_ui.md)。
检测校对菜单中，确认键长按录入指定一帧标准件，短按开启或关闭检测；无有效模板时拒绝开启。
演示使用固定摄像头、纯色哑光背景和单个缓慢移动目标。修改影响边缘的配置后须重新录入。
同一物体出现一次有效 PASS 后锁定“通过”；这也会锁定一次误判 PASS，是当前演示策略的取舍。
尚未通过的目标进入中央区域后，连续可靠离开中央区域才结束待确认并判定未通过。
身份不确定、故障、模板失效及帧不匹配不沿用旧通过结果；未就绪显示等待，不显示 LAST。

仿真入口见 [仿真说明](sim/README.md)。厂商加密 DDR 行为模型可能与部分 ModelSim 版本不兼容；端口声明夹具仅验证接口，不能替代 DDR 行为验证。
